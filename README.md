# Seattle Airbnb Market Analysis
A Tableau dashboard analyzing Airbnb listing prices and revenue trends in Seattle (2016), by bedroom count and zipcode.

##  What's Inside

- **Revenue for Year:** weekly revenue trend across 2016
- **Average Price per Bedroom:** nightly price for 1–6 bedroom listings
- **Distinct Count of Bedroom Listings:** supply by bedroom count
- **Price by Zipcode:** ranked average price per zipcode
- **Price per Zipcode (Map):** geographic view of prices
